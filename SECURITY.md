# Security and Safety Reporting

This repository contains concepts for systems involving high voltage, UV radiation, water treatment, oxygen, hydrogen, and industrial controls.

Do not post credentials, private site layouts, active IP addresses, control-system access paths, or exploitable safety weaknesses in public issues. Report sensitive software or operational-control concerns privately to the project owner through the contact channel published with the repository.

No documentation in this repository overrides OEM instructions, local law, required permits, process-safety review, or qualified engineering judgement.
