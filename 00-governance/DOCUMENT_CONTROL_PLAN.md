# Document Control Plan

## Status labels

| Label | Meaning |
| --- | --- |
| Draft | Working document; uncontrolled |
| P0 | Preliminary issue for review/quotation |
| A | Approved for specified internal use |
| IFC | Issued for construction; only after all release gates pass |
| As-built | Field-verified final configuration |
| Superseded | Retained historical record |

## Required title-block fields

Every controlled drawing, calculation, procedure, and report shall show document ID, title, system, revision, status, author, checker, approver, date, page number, and source-data reference.

## Retention

Retain signed approvals, raw test data, calibration records, supplier certificates, deviation requests, and as-built changes for the applicable product/service period and any legal retention requirement.
