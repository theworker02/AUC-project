# Changelog

## 1.2.0 — Accessible Engineering Package

### Added

- Root-level project index and controlled document catalog for direct navigation.
- Fast system-entry pages for AUC-Air, AUC-Water, and Phyto-Breeze.
- Governance, drawing, P&ID, BOM, supplier, safety, commissioning, maintenance, and claim-approval templates.
- Version and document-control policy for controlled releases.

### Improved

- Documentation portal now carries the official portfolio mark and provides a controlled-document reader.
- Repository structure now separates requirements, design, process, quality, safety, commissioning, and operations records.
- Every preliminary drawing/manufacturing document is explicitly marked as non-construction release until its documented gates are closed.

### Release status

v1.2.0 is a preliminary engineering documentation release. It does not authorize fabrication, hazardous-process operation, performance claims beyond the stated test boundaries, or field construction.

## 0.2.0 — Engineering Repository Foundation

### Added

- Controlled documentation portal and GitHub Pages workflow.
- AUC-Air, AUC-Water, and Phyto-Breeze preliminary manufacturing plans.
- Preliminary drawing register, release control, interface control, manufacturing data requirements, and verification plan.
- Structured engineering repository workstreams, templates, quality records, procurement records, and safety register.
- Official AUC portfolio logo and inactive funding configuration.
- Version, release, contribution, and security-control files.

### Release status

This is a preliminary engineering documentation release. It does not authorize fabrication, hazardous-process operation, performance claims beyond the stated test boundaries, or field construction.

## Version policy

- **Major:** changes to portfolio boundaries or released product claims.
- **Minor:** new controlled engineering packages, modules, or significant verification scope.
- **Patch:** corrections that do not alter an approved requirement or release boundary.
