# AUC Manufacturing Data Requirements

This document defines the minimum information that must be fixed before a supplier receives a build package. It does not invent missing site, OEM, or certification data.

## AUC-Air data to freeze

| Item | Requirement to state on the released drawing or datasheet | Evidence |
| --- | --- | --- |
| Flow | Nominal, minimum, maximum, temperature, pressure, RH, and allowable flow error | Calibrated airflow test |
| Core array | Active area, channel pitch, post-coating hydraulic diameter, open area, axial length, allowable bypass | Dimensional inspection and flow map |
| Cyclone | Actual inlet geometry, grade-efficiency curve, pressure-drop curve, hopper seal, dust service method | CFD plus empirical qualification |
| PAN cassette | Media construction, effective area, gasket compression, clean/loaded pressure-drop curve, replacement condition | Supplier certificate and bench test |
| PCO cassette | Substrate, coating mass/loading, coating method, UVA wavelength/irradiance map, retention criteria | Coupon and cassette qualification |
| MnO2 cassette | Media form, void fraction, EBCT, ozone inlet load, outlet threshold, retention method | Ozone challenge and shedding test |
| Fan | Certified curve, control map, stall margin, acoustic target, motor thermal limit | FAT curve and runtime test |
| Enclosure | Material, coating, access panels, drainage, IP/NEMA target where applicable, lifting and anchorage | Drawing and inspection |

## AUC-Water data to freeze

| Item | Requirement | Evidence |
| --- | --- | --- |
| Climate basis | Hourly dry-bulb, RH, wet-bulb, particulate and source-water dataset | Site survey |
| Yield | L/h and kWh/L at declared conditions and treatment boundary | Pilot test report |
| Air module | Filter class, coil/contact geometry, air flow, pressure drop, condensate pan slope and cleaning access | FAT inspection |
| Water boundary | Utility, process, potable, or OEM DI feed target | Approved water-quality specification |
| Treatment | P&ID, sampling points, off-spec diversion, tank turnover, cleaning, backflow, reject disposal | Commissioning test |

## Phyto-Breeze data to freeze

Phyto-Breeze must be supplied as an OEM-integrated industrial package. Release depends on the selected OEM P&ID, interface-control document, hazardous-area study, HAZOP/LOPA, relief and vent design, gas export/storage design, and calibrated delivery-boundary instrumentation. A conceptual container layout is not a substitute for these documents.

## Supplier submission format

Each supplier quotation must include a completed compliance matrix, deviations list, operating-point evidence, drawings, lead time, warranty, spare-parts list, certificates, inspection plan, FAT procedure, and service manual. Any statement based only on nominal CFM, nominal UV watts, vague removal percentages, or marketing terms is non-responsive.
