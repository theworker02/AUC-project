# AUC Portfolio Build Sequence

## Phase 1 — Evidence and interfaces

1. Establish AUC Sentinel data contracts, calibration record format, fault/event schema, and dashboard requirements.
2. Freeze the AUC-Air benchtop challenge matrix, analytics, statistical endpoints, and pass/fail calculations.
3. Select the intended AUC-Water site and collect at least one season of temperature, RH, rainfall, HVAC-condensate, demand, and electricity data.
4. Obtain Phyto-Breeze OEM candidate data packages without purchasing equipment.

## Phase 2 — AUC-Air benchtop qualification

1. Test TiO2/UVA coupon kinetics, humidity response, byproducts, and aging.
2. Qualify PAN-only particle capture before enabling corona.
3. Measure corona's marginal benefit, O3 generation, and MnO2 removal only if corona remains a candidate.
4. Validate coating retention, pressure drop, airflow distribution, interlocks, and fault response.
5. Release a full-scale AUC-Air design only after the specified endpoint and byproduct limits pass.

## Phase 3 — AUC-Water pilot

1. Begin with a dedicated condensate and rainwater collection pilot; log dry-bulb temperature, RH, wet-bulb temperature, and source-water quality.
2. Keep non-potable plumbing separate from potable plumbing, with backflow protection and permanent labelling.
3. Size storage from site demand and measured source variability.
4. Add an AWG pilot only after site data supports a defensible, stated-condition yield and kWh/L target; use mechanical coil-protection filtration.
5. Compare DX, liquid-desiccant, and no-AWG options using measured climate, energy, maintenance, and available regeneration heat.
6. Treat any PEM feed-water option as a separate, OEM-qualified DI-polishing path.

## Phase 4 — Phyto-Breeze pre-procurement

1. Select a PEM OEM capable of the verified-delivered oxygen target.
2. Obtain the OEM P&ID, interface-control document, operating envelope, crossover limits, and water-quality requirements.
3. Complete hazardous-area classification, HAZOP/LOPA, relief, venting, dispersion, and export/storage engineering for the actual site.
4. Complete the product-verification instrumentation plan.
5. Issue construction documents only after these hold points are approved.

## Shared release rule

No module inherits another module's test result, certification, safety analysis, process line, or emergency response system. Shared branding, energy planning, telemetry, and data visualization do not constitute process integration.
